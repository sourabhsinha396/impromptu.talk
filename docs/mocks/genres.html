Genres: what changes from v0, and why

  • The hub is ten cards with the count on each. Icon in the accent, name, the blurb, and how many topics, so the page says what it holds before anybody clicks. One primary button at the top routes straight into the tool.
  • The genre page groups topics by style. v0 printed a flat list with a small tag on every line. Four headed sections (Just talk, Hot take, Explain it simply, Tell a story) read as a document about the subject, and each heading is a real h2 for the crawler. Every topic is still plain text on the page, which is the rule that makes the page rank.
  • "Practise this genre" is the one button, and it opens the tool with the genre already picked. The breadcrumb goes back to the hub; "More genres" at the bottom keeps every genre one hop from every other.
  • Two columns on a laptop, one on a phone, so 120 topics do not become a wall.
