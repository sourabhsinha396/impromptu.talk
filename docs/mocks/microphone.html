Where do we ask for the microphone?

The problem. Chrome's prompt fires the moment we call for the microphone. Today that is when the topic lands, so it arrives unasked, over the topic, before anybody knows why. An unexplained prompt gets refused by reflex, and "Never allow" is permanent for the site: there is no way to ask again from code, and the person has to find Chrome's site settings to undo it. So asking badly does not cost us an annoyance, it costs the feature for good.

  • Rule one: the browser's prompt may only ever appear because somebody pressed a button of ours that said it would.
  • Rule two: the ten-second rule still outranks this. Nothing new before the one button on home.
  • Rule three: ask when the value is obvious, not before. They have to know what a round is first.
  • Rule four: never be pushy. One offer, once, in one place. "Not now" is final until somebody goes looking in settings.
