The features page: what it is and why it exists anyway

AGENTS.md is explicit: "There is no features page; that is the thing you build once you have lost this argument." This page is that argument, lost on purpose, owner's call - logged as a dated entry in docs/DECISIONS.md in the same change as this mock, per the rulebook's own rule for reversed decisions. The reasoning: as the tool picks up genuinely separate capabilities (image topics, owned genres in two shapes, the streak, the report), a stranger arriving at the homepage has nowhere to see the shape of the whole product without spinning ten times and stumbling into each one - /features is that one page, kept out of the home screen so the ten-second rule still holds there untouched.

What changed

  • One navbar link, "Features", next to the wordmark. Not in the account menu (that stays destinations, not features) and not on the home stage itself, which is unchanged and still just the genre chip, the question and Spin. The link shows on every page's chrome except during a timed round (prep/speak already hide the whole topbar).
  • The page is a flat list of cards, grouped free-forever vs. Pro, in that order for a stranger and Pro-first for a subscriber - the same rule the genre picker already uses for owned genres, applied here for consistency rather than invented fresh. Each card is an entry point: name, one line, and a link into the real surface (the picker, a settings sheet, a sample report), not a page unto itself.
  • Custom genre (text) and custom genre (image) are disabled for a free viewer: no href, muted ink, a "Pro" badge, and no hover state - looked at, not clicked, so a stranger learns the shape of what they'd get without a dead link or a surprise paywall click. Signed in as Pro they behave like every other card.
  • Image impromptu is listed here as planned/soon (muted, no badge) until the mock in docs/mocks/image-topic.html is built for real - this page does not get ahead of that decision, it only names the slot.

Left out on purpose

  • No pricing on this page - that argument belongs to /pro alone, so this page links there rather than repeating it.
  • No screenshots or marketing copy per card - one sentence each, plain nouns, per the rulebook's copy rules.
